# 历史沿革（abyss-queue）

**用途**：代码注释与配置模板只描述"当前是什么"，**沿革一律记在这里**（规则见 [`协作.md`](协作.md) 的「日志、版本号与注释」一节）。
每做一次结构性变更（删配置键、挪模块、改口径、换落点）就追加一行；「说明」写清**变了什么、为什么**，
供以后判断"这处为什么长这样"。

本文件是**总索引**：变更行按模块分册存放（2026-11 从一个 289 KB 的单表拆开，迁入各分册时**一个字都没改**；
编辑器那册最大，2026-11 又按子题拆成五册）。
新增一行时，按这次改动**主要落在哪个模块**判断，追到对应分册的**表末**；一个改动跨多个模块的，
记在"主要落在哪一册"，不必重复记。

**三条不变**：

- **只追加、不改写**：历史行一句都不动（包括当时的判断、当时的口径）；与现在不符时，新行里说明"这条已被 X 取代"。
- **版本摘要不写在这里**：面向使用者的版本级摘要记根目录 [`CHANGELOG.md`](../CHANGELOG.md)；本目录只记"哪次改了什么、为什么"。
- **代码里不写沿革**：注释只讲"现在是什么、为什么这样设计、边界在哪"。
