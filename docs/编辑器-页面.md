# 编辑器 · 页面与版式

> 填写页的结构、缩放、表格、已完成栏、主播区、页脚，以及窄屏口径。
> 入口与部署见 [`../editor/README.md`](../editor/README.md)；交互与写入口径见 [`编辑器-写入与安全.md`](编辑器-写入与安全.md)；
> 沿革见 [`历史沿革-编辑器-页面与交互.md`](历史沿革-编辑器-页面与交互.md)。

## 页面结构

`editor.html` 是单文件（无构建、无外部 CSS）。管理端一套页面、填写页一套页面，共用同一份骨架：

```
左侧栏 .side（#nav：排队 / 总览 / 周期 / 版本 / 改动 / 权限 / 归属 / 填写，一项是 .ni）
主区 .main
  顶栏 .top（当前页标题 + 上次保存 + 口令与操作）
  页面 .page（一次只显示一个：#p-queue / #p-overview / #p-cycles / #p-versions / #p-changes / #p-admins / #p-ownership / #p-fill）
排队页：主播卡片 #acards → 两栏 .work（左：表格 #grid；右：栏 .rail 里的已完成 #doneList）
填写页：页头 .fillhead（#fillTitle + #fillTabs 页签）→ 两栏 .fillgrid（左：表头 #fillHd + #fillGrid；右：已完成 #fillDoneList）
        左下角身份卡 #fillMe（只在 PC 端、`body.fillmode` 下出现）
页脚 #siteFooter（内容来自配置 footer.html）
```

- `body.fillmode` 是填写页形态：隐藏侧栏 `.side` 与顶栏 `.top`，主区撑满整屏；手机端这时靠底部 `#mobPage` 切页。
- 手机档（≤1100px）：行从表格变四区网格，编辑一行从底部升起（`#msheet`），主播卡片横向滚动。
- 弹层四个：`#picker`（选择主播 / 难度目标 / 状态胶囊，共用 `.pk`）、`#nickpick`（群昵称候选，`.pk.nickpick`）、`#msheet`（手机编辑一行）、`#anchorEdit`（编辑主播）。

### 缩放：几个变量 + 四个断点

字号与行高不逐条写死，全从 `:root` 派生（`editor.html` 顶部与各断点段）：

| 变量 | 作用 | 默认 | ≥1500px | ≥1700px | ≥1900px | ≤1500px |
|---|---|---|---|---|---|---|
| `--fs` | 正文字号 | 15px | 15.5px | 16px | 17px | 14.5px |
| `--fs-small` | 小字 | 12.5px | — | — | — | — |
| `--row-h` | 行高（表格行、已完成条目） | 54px | 58px | 60px | 64px | 52px |
| `--hd-h` | 表头高 | 40px | — | — | 44px | — |
| `--side-w` / `--main-left` | 侧栏宽 / 主区左距 | 176 / 190px | — | 190 / 204px | 200 / 216px | 160 / 174px |
| `--rail-w` | 右栏（已完成）宽 | 320px | — | 340px | — | 300px |

- 超宽屏不再逐档加变量，直接整页放大：`min-width:2400px` → `zoom:1.333333`，`min-width:3600px` → `zoom:2`。
- `max-width:1100px` 是手机档；`prefers-reduced-motion:reduce` 关掉全部动效（状态色、文字与回执圆点保留，见下文「动效」）。

### 表格（排队中）

- 不是 `<table>`，是 `#grid` 里一列 `div.tr`，用 `grid-template-columns: var(--cols)` 对齐；`--cols` 按断点给三套（序号 / 昵称 / 游戏名 / 主播 / 难度及目标 / 状态 / 备注 / 操作），`#fillHd` 与数据行共用同一套。
- 列宽用 `minmax()`：长文本列（目标、备注）先吃掉富余，窄屏先压昵称与备注。
- 只读态把昵称 / 游戏名 / 备注渲染成纯文本（`input` 会被裁掉），单元格允许换行；只读访客的操作列不渲染删除按钮。
- 每行带 `data-row`（表格行号），断言按它找行。

### 已完成栏（右栏）

- 与主表同一份数据，顶部是 `#doneCount`（已完成 / 总数）、`#donePct` 与进度条 `#doneBar`；填写页同名的 `#fillDoneCount` / `#fillDonePct` / `#fillDoneBar`。
- 条目是 `.drow`（一行式，圆角胶囊、悬停浮起）：`.who2` 名字 + `.an` 完成人；名字过长换行而不是省略号。
- 面板 `.donelist` 固定 `max-height:56vh`、内部滚动，高度不随内容变化（不会把页面越推越长）。

### 主播卡片

- 只读是 `#acards` 卡片网格（`.acard`：5 列 → 3 列 → 手机横向滚动），公共队列那张卡隐藏呼叫与编辑键。
- 可编辑态点 `.aedit` 打开 `#anchorEdit` 抽屉（表单在 `#aeBody`），不再在卡片里直接输入。
- 推荐度用 `.recchip` 五档色（与编辑器的 `REC_TONE` 同一套语义），说明小字随 `--fs`。
- 卡片顺序按服务端下发的 `recRank`（与 `#主播` 出图同一口径），同档按名字；公共队列那张永远最后。


### 动效

一套节奏 token（`:root` 里的 `--aq-dur-xs/s/m/l` = 90 / 150 / 220 / 300ms，`--aq-ease-std` / `--aq-ease-enter` /
`--aq-ease-exit` 取自 Material 3 的 standard / emphasized-decelerate / emphasized-accelerate），PC 与手机共用；
样式在 `editor.html` 的「动效（2026-11 第二轮）」段，分五节，**每节可整段删掉**，脚本只负责挂状态类、不碰时序。

| 节 | 动什么 | 脚本挂点 |
|---|---|---|
| ① 切页与切榜 | 切页时页面各块依次上浮 6px；读取占位 `.centered.loading` 350ms 内读完就不出现；切榜时表格 / 主播卡 / 已完成列表淡入 | `body[data-swap]`（点榜签时 a / b 轮换） |
| ② 按压回执 | 按钮、榜签、浮层选项按下缩 3%（手机没有 hover，这是唯一的「点到了」）；表格行只压暗底色不缩放 | iOS 需要一个空的 `touchstart` 监听 |
| ③ 保存回执 | 顶栏 `#saveState`（填写页另有 `#fillSaveState`）与行首 `.seqcell` 同一颗圆点：待存暗金 → 写入中墨蓝呼吸 → 存好绿点弹出（行首那颗随后淡去）/ 没存上红色光环 | `setState(kind)` 的 `is-<kind>`；行上 `is-dirty / is-busy / is-saved / is-bad`（`rowStateClass()`） |
| ④ 三层对象的来处 | 浮层从触发点长出（往上翻时原点换到下沿）、抽屉从屏幕边升起（手机贴底整张推上来）、模态在中央放大；被点走快速收回，15 秒到点原地慢慢淡出；提示条到点前先沉下淡出 | `.pk[data-side]`（`place()`）、`.pk[data-close=auto]`（`armAutoClose()`） |
| ⑤ 刻意不动 | 滚动、数字、保存后的整表重绘、悬停浮起、列表逐条入场 | — |

- 退场靠 `transition-behavior: allow-discrete` 让 `display:none` 等动画走完；不支持的浏览器退回硬切，入场不受影响。
- 关键帧只动 `opacity` / `transform` / `box-shadow` / 底色，不改尺寸；每个动画在减弱动态效果下都有对应的 `animation:none`（`test/layout.test.mjs` 两条都钉住）。
- **静态截图**：以减弱动态效果渲染（Playwright `reducedMotion: 'reduce'`）即为终态——入场一律 `backwards` 填充、结束不残留 `transform`。
  不要用 `animations: 'disabled'`：它会把提示条的退场快进到终点，截出来提示条是透明的。

## 页脚（版权 / 备案）

页脚内容**不写死在页面里**，由配置 `footer.html` 提供；前端从 `GET /api/meta` 取它（**与其它请求共用同一个 `withToken()`**：
主脚本开局就把 `?k=` 收进 localStorage 并把地址栏清干净，再自己读 `location.search` 会拿到空口令 → 403 → 页脚静默消失）。

```yaml
footer:
  html: |
    <div>© 2026 <a href="https://github.com/Hyposelenia-Moon">缄月</a> &amp; <a href="https://github.com/AxiuCN">阿修Axiu</a> · 由 <a href="https://github.com/Hyposelenia-Moon/abyss-queue">abyss-queue</a> 提供</div>
    <div><a href="https://beian.miit.gov.cn/" target="_blank" rel="noreferrer">京ICP备2026xxxxxx号-1</a></div>
```

- **规范署名行由编辑器追加**：自由 HTML 之后自动补一行 `Created By {框架名} {yunzaiVersion} & {PluginName} {pluginVersion}`
  （口径见 [`协作.md`](协作.md)）。框架名按宿主 `package.json` 的 `name` 判（含 `trss` ⇒ `TRSS-Yunzai`，其余 `Yunzai-Bot`）；
  版本取编辑器定位到的插件根下 `package.json`，插件名取 `components/constants.js` 的 `PLUGIN_NAME`；都推不到时显示「未知」。
  所以维护者改署名**不用管版本号**，也别把版本号抄进 `footer.html`。
- **署名口径**：首行两位维护者并列（缄月 / 阿修Axiu），与 `AGENTS.md` 的权属一致；`&` 建议写 `&amp;`。
- **备案号留给你**：不预填，避免把示例号带上线。
- **自由 HTML，不拆字段、不校验**：版权几行、备案号放哪、要不要公安备案、甚至放图片都由维护者排；编辑器只"有就画、
  没有就不画"（空串 = 整块不渲染）。
- **覆盖四处**：填写界面 + 三个提示页（需要口令 / 仅主人可用 / 链接已失效）。提示页在鉴权之前返回，由服务端直接拼进 HTML；
  填写界面走 `GET /api/meta`、前端 `innerHTML` 插入。
- **只由维护者维护**：它被当作可信内容原样插入页面，**不要**把群友可控的字符串接到这里（等于给公网页面留 XSS）。
- 改完要**重启机器人**才生效（配置只在插件加载时读一次）；编辑器跑在机器人进程里，没有"单独重启编辑器"这回事。

## 手机端（≤820px）：一行一张卡片

`thead` 隐藏、每个 `td` 前面用 `data-k` 当代字段名，并且**只留三列**：

- **别人的行**：序号 / 群昵称 / 帮帮完成情况（其余折起来，一屏能多看几个人）；
- **自己那一行整行展开**（`tr.own`）：`perm.roam === false`（名单不可信 / 链接里没有名片）时服务端**只发自己那几行**；
  本群成员（`roam`）拿到整张表 ⇒ 按**群昵称**认自己那行（打开页面时服务端已按 QQ 把这行同步成群名片）。
  两种视图是**分开的**：`own` 逐行打（`renderGrid`）、`see-all` 整表打（`renderPerm`）——从前 `own` 也是 body 级，
  结果普通人一进页面**所有行**都展开，"只看自己那一行"等于没有。
- **「序号」那一格必须 `padding: 0`**：PC 那条 `td.rowno { padding: 0 8px }` 不覆盖的话，字段名会被顶进 8px、与其它行对不齐。
- **锁定格的完成情况一颗值一颗胶囊**（与可编辑的多选格同一套 `/[,，]/` 拆分与底色口径）：整串塞一颗时 `pillColor` 认不出
  「阿修Axiu,听雨」是哪一类，会画成一颗黄底大胶囊。这个只读分支**只有非 admin 走得到**
  （`statusLocked = caller.role !== "admin" && …`）。

回归见 `editor/test/client-state.test.mjs` 的「手机端①/①续/②/③」。

## 手机端（≤1100px）：页面切换、两套页面

- **页面切换**：侧栏 `.side` 收起，`#mobPage` 复用 `show(id)`——选项由 `renderMobNav()` 按权限生成（排队表打头、其余取
  `#nav .ni` 里当前可见的页面），切换时同步 `#crumb`、`.ni.on` 与地址栏 hash；更宽视口 `.mobpage{display:none}`。
  2026-11-25 起它从左下角浮动胶囊改成**通栏贴底**（`position:fixed;left:0;right:0;bottom:0`，`body` 底部留 76px）——
  原来那颗固定在下左，正好压住排队表第 3、4 行的群昵称。
- **两种身份两套页面**：主人 / 管理员只有管理那七页，**没有填写页**，报名走排队表底部「＋ 新增一行」；
  普通成员（`perm.role === 'self'`）与只读访客（`guest`）**只有「排队表 · 填写」**这一页，PC 侧栏与手机下拉都只出它，
  进来直接落这页（`load()` 里 `show('fill')`）。填写页底部同样有「＋ 新增一行」（只读置灰），没报名的人点主按钮「我要报名」
  就**就地建一行**。三类按钮的显隐都在 `applyPerm()`（`fillOnly`）与 `renderMobNav()` 里。
- **「管理台 /」前缀**：`.adminonly` 只给 `owner / admin / manage` 身份，其他身份在手机与桌面都不显示。
- **「当前选中」卡**：`#selBody` 与 `#fillSelBody` 同为 `.card.selcard`，≤1100px 隐藏、桌面保留（约 150px）；「已完成」列表不隐藏。
- **「我的报名」**：以服务端下发的 `mineRows`（按 QQ 绑定 / 唯一同名认出来的行号，每榜最多一行）为准，页面不再自己按昵称
  `find`；服务端也认不出、表里又有多个同名行时写「待核对」、主按钮写「我的报名待核对」并提示联系管理员，不猜也不建行。

回归：`editor/test/client-state.test.mjs` 的「成员只有填写页，管理员没有填写页」「就在填写页点「＋ 新增一行」报名」
「只读访客点「我要报名」不建行」「同名多行且服务端认不出」；服务端 `mineRows` 在
`editor/test/member-row-area.test.mjs` 的「本人（self）的合法追加仍然可用」。

## 手机端排队区（≤1100px）

- **一行读完**：每行是 `grid-template-areas:"seq nick stat call"` 的四区网格——序号在左、群昵称居中偏左、完成情况胶囊靠右、
  呼叫在最右；「编辑」是昵称右端的 34×34 方形小键（`[data-medit]`，点它开抽屉）。
- **攻炼榜另排**：完成情况是多段复合值（`7.2排队中 7.3等待开启`），硬塞进四区会把昵称压成竖排，所以
  `body.attack-sheet .tr` 改成「序号 / 昵称 / 呼叫」一行、状态落到第二行右侧。
- **昵称格只读**：`rowHTML()` 按 `isNarrow()`（`matchMedia('(max-width:1100px)')`，与 CSS 同一个断点）给昵称格加 `disabled`，
  `bindGrid()` 挂候选的条件也加 `!isNarrow()`。改昵称走右边的「编辑」小键开抽屉（`#msheet` 第一行就是群昵称输入框）；
  桌面档不受影响——表格里直接改昵称容易误触候选、把行挤乱。
- **浮层 15 秒自动收**：`.pk` 浮层（选择主播 / 目标 / 状态胶囊 / 群昵称候选）打开时由 `armAutoClose(host, close)` 记计时器，
  `PK_AUTO_CLOSE_MS = 15s` 到点若还开着就收；重开或重画清掉旧计时器重算（只有"一直没动静"才算超时）。计时器按浮层元素各记
  一个（`pkTimers`），`#picker` 与 `#nickpick` 互不影响。
- **输入框 16px**：`.cellinput` 与抽屉 `.msrow input` 都是 16px，低于这个字号 iOS 会在聚焦时放大整页。
- **页脚与副标题对比度**：`.site-footer` / `.fillfoot` / `.anchors-head .sub` 统一 `#5f6b7d`（浅玻璃底上约 5:1）；填写页里
  `.fillfoot` 与 `#siteFooter` 同时出现会重复署名，所以 `body.fillmode #siteFooter{display:none}`。
- **填写页页头竖排**：`.fillhead` 在窄屏改 `flex-direction:column`，标题 34px → 26px、`#fillSaved` 左对齐——并排时右侧那串
  「上次保存 2026/11/26 01:57:02」占 ~150px，390px 屏上 34px × 6 字只剩不到 200px，会断成两行。桌面档仍并排。
- 390×844 实测整页 1722 → 1368px。

回归：`test/layout.test.mjs`（`.medit{` 与 `data-medit=`、页头竖排）；`editor/test/client-state.test.mjs` 的「手机抽屉」「手机端页面切换」
「手机档昵称格只读」「浮层 15 秒没动静自己收起」。

## 呼叫按钮的点击回执

- **按下**：`.callbtn`（表格行）/ `.acall`（主播卡）带 `transition:transform .12s ease,box-shadow .12s ease,background .16s ease,color .16s ease`，
  `:active` 时 `transform:translateY(1px) scale(.96)`。
- **发出之后**：`callMember()` / `callAnchor()` 成功后给按钮加 `.called`（蓝底白字，`900ms` 后由 `flashCalled()` 摘掉）；
  失败**不加**——别把失败画成成功。
- 回归：`editor/test/anchors.test.mjs` 两条 + `test/layout.test.mjs` 一条源码契约（`:active` 位移、`transition`、`.called`、
  页面里真的 `classList.add('called')`）。

## 群昵称候选浮层

- **点开才出、空输入摆前 8**：昵称格与填写页的昵称输入框聚焦即弹 `#nickpick`（独立的 `.pk.nickpick`，**不复用** `#picker`
  ——两个浮层各管各的生命周期）；空输入列名单前 `NICK_BROWSE_LIMIT = 8` 个名片，标题「群成员名单 · 点一下填入」；
  有字实时筛：一字不差置顶（-1 分），前缀 0 分、包含 1 分、不小于两字且最长公共片段 ≥2 且编辑距离 ≤2 给 `2 + 距离` 分，

## 填写页左下角身份卡

填写页（`#fill`）运行时 `body` 带 `fillmode`，它把侧栏与顶栏一起藏掉（`body.fillmode .side{display:none}`、
`body.fillmode .top{display:none}`），所以 PC 上左下一片空白。补一张紧凑身份卡：

- **标记**：`</aside>` 之后 `<div class="me fillme" id="fillMe">`（`#fillMeAv` / `#fillMeName` / `#fillMeRole`），复用 `.me` / `.av`。
- **只在这两种情形出现**：`body.fillmode`（填写页）且不是手机档；手机档在 `@media (max-width:1100px)` 里显式
  `body.fillmode .fillme{display:none}`——底部被 `.mobpage` 切页条占着，会叠在一起。
- **同一份数据画两处**：`applyPerm()` 里的 `paintMe(avId, nameId, roleId)` 一次更新侧栏与填写页（名字、权限 + 只读态、
  头像同源代理图；`onerror` 摘图回落首字）。权限文案把 `p.role === 'self'` / `'guest'` 映射成「群友」/「访客」，不再印英文。
- 回归：`editor/test/client-state.test.mjs` 两条（两份一致 + 只读态「访客 · 只读」）；`test/layout.test.mjs` 一条静态契约。
