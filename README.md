# abyss-queue（三路深渊排队）

TRSS-Yunzai 插件：在 QQ 群里查三路深渊的排队情况，并附带一个随机器人一起跑的网页编辑器。

四张榜——**幻想真境剧诗 / 幽境危战 / 深境螺旋 / 绝境攻炼**（榜名可改，插件按表内内容识别）。状态存在本机 `data/queue.json`（唯一事实源），`data/queue.xlsx` 只是导出镜像；编辑器挂在机器人自己的 HTTP server 上（前缀 `/queue`），同进程、同启停，是唯一的写入口。

> 本文件只讲装、用与命令。业务口径、页面细节、数据结构、测试与协作约定见文末「文档索引」。

## 功能一览

- 群内一张图看懂四个榜的人数与本人排队状态
- 单榜队列、主播列表与开播状态
- 自助退队；主人与白名单管理员可插队、维护主播与清榜
- 开播提醒订阅
- 网页编辑器：排队表 / 概览 / 清榜安排 / 历史版本 / 改动记录 / 权限管理 / 归属状态，手机端同功能
- 链接身份 + 群名单鉴权：改别人的行受额度与红线限制；写表带版本与行指纹，冲突回 409，不覆盖别人的改动

## 安装

在 Yunzai 根目录执行：

```bash
git clone --depth=1 https://github.com/Hyposelenia-Moon/abyss-queue.git ./plugins/abyss-queue/
pnpm install --filter=abyss-queue
```

然后三步：

1. 把 `resources/空模板.xlsx` 复制成 `data/queue.xlsx`（起始表，编辑器首次启动据此生成 `queue.json`）。
2. 启动一次机器人：`editor.token` / `editor.sign_key` 为空会自动补齐（只写这一次），主人 QQ 同时写进编辑器白名单。
3. 在 `config/config.yaml` 的 `editor` 段填 `public_url`——群友能打开的编辑器地址，只用于拼链接，插件不向它发请求。

之后改凭证或 `notify.cron` 需**重启 Yunzai**。反代、nginx 与安全口径见 [`editor/DEPLOY.md`](editor/DEPLOY.md)。

## 使用

| 命令 | 谁 | 干什么 |
| --- | --- | --- |
| `#排队` | 所有人 | 四榜人数总览 + 本人排队信息（一张图） |
| `#排队 <榜>` · `#<榜>排队` · `#<榜>列表` | 所有人 | 某一榜的队列 |
| `#主播` · `#主播 <榜>` · `#主播 <名字>` | 所有人 | 主播列表（合并 / 单榜 / 单人详情） |
| `#退队 <榜>` · `#退队 全部` | 所有人 | 退出自己的排队 |
| `#插队 [<群昵称>] [<榜>]` | 主人 / 白名单 | 挪到「排队中」最前面 |
| `#开播提醒` · `#开播提醒 开/关 [主播]` | 所有人 | 查看 / 设置自己的开播提醒 |
| `#排队直播状态` | 所有人 | 强制刷新一次直播状态 |
| `#排队帮助` · `#排队菜单` · `#深渊帮助` | 所有人 | 帮助页 |
| `#排队同步名单` | 主人 | 立刻扫一次群成员名单并推给编辑器 |

榜名可写全名、简称或序号（1 起）。`#排队` 在群里发的是「一张图 + 一段填写情况 + 固定页短链」：口令 5 分钟有效，消息 30 秒后自动撤回；完整长链接只走私聊（QQ 风控群内长外链），管理员与主人那份同样只走私聊。

## 编辑器

入口是 `<public_url>/#code=<6 位数字>`（群聊里点进去就是它）。两套页面：**主人 / 管理员**有七个管理页，报名走排队表底部「＋ 新增一行」；**普通成员 / 只读访客**只有「排队表 · 填写」一页。权限只按稳定 QQ 判，群昵称不能当身份。手机端（≤1100px）侧栏收起、底部下拉切页，浮层 15 秒无操作自动收起。

页面、四档权限、写表与安全、链接身份分别见 [`docs/编辑器-页面.md`](docs/编辑器-页面.md)、[`docs/编辑器-权限与归属.md`](docs/编辑器-权限与归属.md)、[`docs/编辑器-写入与安全.md`](docs/编辑器-写入与安全.md)、[`docs/编辑器-链接与认领.md`](docs/编辑器-链接与认领.md)。

## 注意

- **宿主冷却会吞消息**：同群同一人 2 秒、同群 0.5 秒内的消息在规则匹配前就被丢弃，冷却期发命令没有回复。
- **命令冲突**：装了别的插件时，裸榜名（如 `#幽境危战`）可能被先接走，请用 `#排队 <榜>` 这类带后缀的写法。
- **更新走框架**：`#更新 abyss-queue`（拉最新代码并重启）、`#强制更新 abyss-queue`（`reset --hard` 对齐远端，会丢弃本地改动）。
- **表里没有 QQ 号列**：认人靠群昵称 + QQ 绑定（首次按昵称认下，之后跟人走）。
- **填表内容对全群可见**：拿到链接就能读到整张表，别把隐私写进备注。
