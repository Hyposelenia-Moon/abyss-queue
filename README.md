# abyss-queue（三路深渊排队）

在 QQ 群里查深渊排队：机器人读**本机**的状态文档 `data/queue.json`（唯一事实源），渲染成图发出去；
同目录的 `data/queue.xlsx` 是它的**导出镜像**（给 Excel 看、下载、历史版本用），不是第二个事实源。

四张榜：**幻想真境剧诗 / 幽境危战 / 深境螺旋 / 绝境攻炼**。榜名可以自己改，插件按表内内容识别，不写死。

编辑器在 `editor/`，由插件挂到**机器人自己的 HTTP server**（前缀 `/queue`），同进程、同启停——不是另起一台服务。
它是**唯一的写入口**：插件自己不写表，要写就经 `editor/service.js` 直调进程内同一份实现（同一套锁、版本与审计）。

> 本文件只讲装、用与命令；业务口径、页面细节、数据结构、测试与协作约定见文末「文档索引」。

## 能做什么（命令速览）

| 命令 | 谁 | 干什么 |
| --- | --- | --- |
| `#排队` | 所有人 | 四榜人数总览 + 本人排队信息（一张图），后接填写情况与填报入口 |
| `#排队 <榜>` · `#<榜>排队` · `#<榜>列表` | 所有人 | 某一榜的队列；榜名可写全名、简称或序号 |
| `#主播` · `#主播 <榜>` · `#主播 <名字>` | 所有人 | 主播列表（合并 / 单榜 / 单人详情，含开播状态） |
| `#退队 <榜>` · `#退队 全部` | 所有人 | 退出**自己**的排队（一榜或全部），退完自动整理该榜 |
| `#插队 [<群昵称>] [<榜>]` | 主人 / 白名单管理员 | 把某人挪到「排队中」最前面；不带参数挪自己 |
| `#开播提醒` · `#开播提醒 开/关 [主播]` | 所有人 | 查看 / 设置**自己**的开播提醒（旧写法 `#排队开播提醒` 也认） |
| `#排队直播状态` | 所有人 | 强制刷新一次直播状态（调试用，忽略缓存） |
| `#排队帮助` · `#排队菜单` · `#深渊帮助` | 所有人 | 帮助页（图片，失败回退同源文本） |
| `#排队同步名单` | 主人 | 立刻扫一次群成员名单并推给编辑器 |

共 **8 条**注册规则（上表 9 行：榜名那两行落在同一条正则上）。聊天端只负责**查询**；
`#插队` / `#退队` 也只是把「哪一榜、哪一行、怎么挪」交给编辑器。
初始凭证与编辑器白名单由**启动流程**首次自动补齐，不用再发命令。

榜名可写全名、简称或序号（1 起）。简称：剧诗 / 幻想 / 真境剧诗、危战 / 幽境、深渊 / 螺旋 / 深境、
攻炼 / 枪战 / 绝境。**不支持 `#排队 全部`**（要看整体请到编辑器或表格）。两条细则：`#退队` 只处理
调用者自己（管理员也不能替别人退，已完成的行不许退）；`#插队` 本来就在最前时回一句「已经在最前面」。

### `#排队` 回什么

- **群聊**：一张图 + 两段文字。填写情况是**三段、顺序固定**：`未填：…；排队中：…；已完成：…`（空的段不写）；
  入口是**固定页 + 6 位数字口令**：`点此填表：<editor.public_url>/#code=<6位数字>`，口令 **5 分钟**有效。
  这条群消息**发出 30 秒后自动撤回**（要新的就再发一次 `#排队`；管理员与主人那份走私聊，不撤）。
- **完整长链接只走私聊**（QQ 会风控群里的长外链）：`?k=&u=&s=&w=&ws=`——身份签在 `u/s`、时间窗签在
  `w/ws`（5 分钟，过期重发一次 `#排队`）。**主人与白名单管理员**那一份整条走私聊，群里一个字都不发；
  私聊失败只在群里回一句原因。
- 链接等同身份凭证（身份窗口 30 天），威胁模型见 [`editor/DEPLOY.md`](editor/DEPLOY.md)。

## 安装与部署

在 Yunzai 根目录执行 `git clone --depth=1 https://github.com/Hyposelenia-Moon/abyss-queue.git ./plugins/abyss-queue/`
再 `pnpm install --filter=abyss-queue`。然后在 `config/config.yaml` 的 `editor` 段填：

| 键 | 作用 |
| --- | --- |
| `editor.public_url` | 群友能打开的编辑器地址，**只用于拼链接**，插件不向它发请求 |
| `editor.token` / `editor.sign_key` | 访问口令 / 身份签名密钥（**两者不能相同**，空着会在首次启动时自动生成） |
| `editor.admin_token` | 管理口令（可选；页面带 `?a=<这段>` 即主人身份，用来维护白名单） |

其余键与注释以 [`config/config.yaml.example`](config/config.yaml.example) 为准，锅巴与热重载见 [`docs/配置.md`](docs/配置.md)。

三步启动：

1. **放一份起始表**：把 `resources/空模板.xlsx` 复制成 `data/queue.xlsx`。编辑器首次启动时按它生成
   `data/queue.json`；此后 json 是事实源，xlsx 变成导出镜像。起始表与 json 都没有时编辑器**不挂载**
   （fail-closed：记一行 error，机器人照常跑）。
2. **启动一次机器人**：`editor.token` / `editor.sign_key` 为空会**自动补齐**（只写这一次，之后不再动），
   同时把主人 QQ 写进编辑器白名单。要自己填的只有 `editor.public_url`。
3. 之后再改凭证或 `notify.cron` 要**重启 Yunzai**（凭证是插件加载时交给编辑器的，不重启会出现
   「插件用新口令、编辑器还认旧口令」）。编辑器挂在机器人自己的端口（`server.port`，默认 2536），
   nginx 与安全口径见 [`editor/DEPLOY.md`](editor/DEPLOY.md)；数据固定 `<插件根>/data`，不可配置。

> **填表内容对全群可见**：编辑器口令在每个人的填表链接里，拿到链接就能读到整张表。本群成员还能改别人
> 的行（受额度与三条红线限制），所以别把隐私写进备注。

## 编辑器：入口、页面与权限

编辑器地址是 `<editor.public_url>/#code=<6 位数字>`（群聊里点进来就是它）。**两种身份两套页面**：

- **主人 / 管理员**：侧栏七页 **排队表 / 概览 / 清榜安排 / 历史版本 / 改动记录 / 权限管理 / 归属状态**；
  没有填写页，报名走排队表底部「＋ 新增一行」。
- **普通成员 / 只读访客**：只有一页 **排队表 · 填写**（PC 侧栏与手机下拉都只有它，进来就落这页），
  只看得到自己的行；底部同样能「＋ 新增一行」（只读访客那颗是灰的）。

**手机端（≤1100px）**侧栏收起，底部通栏页面下拉；排队表每行一行读完（序号 / 群昵称 / 完成情况 / 呼叫），
「编辑」是昵称右侧的小键，点开抽屉改整行（手机上昵称格只读）；浮层 15 秒没动静自动收起。
页面与交互见 [`docs/编辑器-页面.md`](docs/编辑器-页面.md)。

**权限只按稳定 QQ 判**（群昵称不能当身份）：

| 角色 | 能做什么 |
| --- | --- |
| 主人（`owner`，或页面带 `?a=<管理口令>`） | 全部：白名单与归属重建、清空无主行、周期清榜、呼叫成员、主播列表、历史版本与回退、改动记录 |
| 白名单管理员（QQ 在 `abyss-editor-admins.json`） | 改所有人的行、主播列表、历史版本与回退、呼叫成员、改动记录看全部；**不能**清榜，没有权限管理与归属状态两页 |
| 群成员（有身份签名且在名单里） | 改整张排队区（自己的行不限；别人的行受额度与三条红线）、呼叫主播、收录临时成员名、看自己相关的改动记录 |
| 不在名单 / 链接过期 / 只有口令 | 只读 |

群成员**不是**「只能改自己那一行」：名单可信时整张排队区都能改，改别人的行有额度（一次 ≤3 行、
10 分钟 ≤10 行）与三条红线（清空别人的行、改别人行的群昵称、主播锁）；名单不可信（空或超 48 小时）
时退回老口径：只能碰自己那一行。判据见 [`docs/编辑器-权限与归属.md`](docs/编辑器-权限与归属.md)。

**写表**：输入即改，停手 **1.2 秒**自动保存；每次保存带 `version`（表指纹）与每行 `fp`（行指纹），
对不上回 **409**、一个字都不写——判的是**行级冲突**，不会盖掉别人刚改的。写失败不自动重试，
版本冲突时草稿不动、自动保存暂停。详见 [`docs/编辑器-写入与安全.md`](docs/编辑器-写入与安全.md)。

## 使用与限制

- 宿主冷却会吞消息：TRSS 的 `singleCD`（同群同一人，默认 2000ms）与 `groupCD`（同群，默认 500ms）
  在规则匹配**之前**丢弃消息，冷却期发 `#排队` 不会有回复。
- 表里**没有 QQ 号列**：认人靠群昵称 + QQ 绑定（首次按昵称认下，之后跟人走）。
- 表格被 Excel / WPS 打开时写入可能 `EPERM / EBUSY`：编辑器提示关闭后重试，不会写坏原文件。
- 出图的**主播排序仍按旧推荐度口径**（页面已按五档「夯 / 顶级 / 人上人 / NPC / 拉完了」排序）——
  已知问题，改 `components/render.js` 的 `recRank` 即可。
- 清榜 / 翻状态 / 插队 / 退队都要求**编辑器已挂载**；起始表与 json 都缺时不挂载，这些动作直接报错。

**命令冲突**：规则先命中先执行（`priority` 升序）。会被别的插件抢在前面的：

| 被抢的命令 | 占用者 |
| --- | --- |
| `#幽境危战` / `#幻想真境剧诗` / `#深境螺旋` / `#深渊` / `#危战` / `#剧诗` | `Axiu-Plugin`「终局挑战」（priority 1） |
| `#排队` | 框架示例 `plugins/example/排队.js`（priority 500） |

所以本插件要求 `#排队 <榜>` / `#<榜>排队` / `#<榜>列表` 这类带后缀的写法。

**表格要求**（手工维护或替换起始表时）：必须是 `.xlsx`；每张表有一行表头且 **A 列写「序号」**，
表头之上是主播区；数据列按表头关键字识别；三列下拉会被当合法选项读出；A 列序号公式不要改。
完整清单见 [`docs/queue.schema.md`](docs/queue.schema.md) §9。

## 更新约定

`#更新排队` 已随 3.0.0 下线，更新一律走框架：`#更新 abyss-queue`（拉最新代码并重启）、
`#强制更新 abyss-queue`（`reset --hard` 对齐远端，**丢弃被跟踪文件的本地改动**）、`#全部更新`（全部插件）。
⚠️ `#更新 abyss`（缩写）**不生效**：框架命中但解析不出 `plugins/abyss`，命令被吃掉且无回复。

两条硬约定：① **配置与数据只以模板入库**——仓库跟踪 `config/config.yaml.example`，`config.yaml` 由首启复制，
`data/` 被忽略，所以更新不碰配置与数据；② **部署目录只由更新指令改动**——不要手工复制代码进
`plugins/abyss-queue`（会和远端提交重叠），改动先在源仓库落地并推送，再 `#更新 abyss-queue`。
