# abyss-queue（三路深渊排队）

在 QQ 群里查深渊排队：机器人读**本机**的状态文档 `data/queue.json`（唯一事实源），渲染成图发出去。
同目录的 `data/queue.xlsx` 是它的**导出镜像**（给 Excel 看、下载、历史版本用），不是第二个事实源。

四张榜：**幻想真境剧诗 / 幽境危战 / 深境螺旋 / 绝境攻炼**。榜名可以自己改，插件按表内内容识别，不写死。

编辑器在 `editor/`，由插件挂到**机器人自己的 HTTP server**（前缀 `/queue`），与机器人同进程、同启停——
不是另一台服务器，也没有单独的进程要维护。它是**唯一的写入口**；插件自己一个字都不写表，要写就经
`editor/service.js` 直调编辑器进程内的同一份实现（同一套锁、版本与审计）。

> 本文件只讲装、用与命令；业务口径、编辑器细节、数据结构、测试与开发约定见文末「文档索引」。

## 能做什么（命令速览）

| 命令 | 谁 | 干什么 |
| --- | --- | --- |
| `#排队` | 所有人 | 四榜人数总览 + 本人排队信息（一张图），后接填写情况与填报入口 |
| `#排队 <榜>` · `#<榜>排队` · `#<榜>列表` | 所有人 | 某一榜的队列；榜名可写全名、简称或序号 |
| `#主播` · `#主播 <榜>` · `#主播 <名字>` | 所有人 | 主播列表（合并 / 单榜 / 单人详情，含开播状态） |
| `#退队 <榜>` | 所有人 | 退出**自己**在某一榜的排队（一次一个榜），退完自动整理该榜 |
| `#退队 全部` | 所有人 | 退出**自己**在所有榜的排队 |
| `#插队 [<群昵称>] [<榜>]` | 主人 / 白名单管理员 | 把某人挪到「排队中」最前面；不带参数挪自己 |
| `#开播提醒` · `#开播提醒 开/关 [主播]` | 所有人 | 查看 / 设置**自己**的开播提醒（旧写法 `#排队开播提醒` 兼容） |
| `#排队直播状态` | 所有人 | 强制刷新一次直播状态（调试用，忽略缓存） |
| `#排队帮助` · `#排队菜单` · `#深渊帮助` | 所有人 | 帮助页（图片，失败回退同源文本） |
| `#排队初始化` | 主人 | 生成口令与签名密钥、写白名单、探活，三步一次做完 |
| `#排队同步名单` | 主人 | 立刻扫一次群成员名单并推给编辑器 |
| `#更新排队` | 主人 | 框架 `#更新` 的简写：拉本插件最新代码并重启 |

共 **10 条**注册规则（上表前两行是同一条规则的两种写法）。聊天端只负责**查询**；
`#插队` / `#退队` 也只是把「哪一榜、哪一行、怎么挪」交给编辑器。

榜名可写全名、简称或序号（1 起）。简称：剧诗 / 幻想 / 真境剧诗、危战 / 幽境、深渊 / 螺旋 / 深境、
攻炼 / 枪战 / 绝境。**不支持 `#排队 全部`**——要看整体请到编辑器或表格。

- `#退队` 只处理调用者自己（管理员也不能替别人退）；已完成的行不允许退队
  （回「已完成（原第 N 位），不予退队」）。
- `#插队` 本来就在最前面时什么也不做，回一句「已经在最前面」。

### `#排队` 回什么

- **群聊**：一张图后跟两段文字——填写情况、填报入口。
  填写情况是**三段、顺序固定**：`未填：…；排队中：…；已完成：…`（空的段不写）。
  入口是**固定页 + 6 位数字口令**：`点此填表：<editor.public_url>/#code=<6位数字>`，口令 **5 分钟**有效。
- **完整长链接只走私聊**（QQ 会风控群里的长外链）：`?k=&u=&s=&w=&ws=#v=`。`v` 是链接标记，
  每发一次就换一个，编辑器只认该 QQ **最新**那一条可写，其余只读——想作废转发出去的链接，重发一次 `#排队` 即可。
- **主人与白名单管理员**那一份整条走私聊，群里一个字都不发；私聊失败只在群里回一句原因，
  不会把管理链接退回群里。
- 链接等同身份凭证：身份窗口 30 天，威胁模型见 [`editor/DEPLOY.md`](editor/DEPLOY.md)。

## 安装与部署

在 Yunzai 根目录执行：

```bash
git clone --depth=1 https://github.com/Hyposelenia-Moon/abyss-queue.git ./plugins/abyss-queue/
pnpm install --filter=abyss-queue
```

配置只需先填好编辑器那四项（`config/config.yaml` 的 `editor` 段）：

| 键 | 作用 |
| --- | --- |
| `editor.public_url` | 群友能打开的编辑器地址，**只用于拼链接**，插件不向它发请求 |
| `editor.token` | 访问口令（插件与编辑器共用这一份，会出现在每个人的链接里） |
| `editor.sign_key` | 身份签名密钥（**不要与口令相同**；留空或相同，编辑器拒绝启动） |
| `editor.admin_token` | 管理口令（可选；页面上 `?a=<这段>` 即主人身份，用来维护白名单） |

其余键与注释以 [`config/config.yaml.example`](config/config.yaml.example) 为准，
锅巴与热重载的机制见 [`docs/配置.md`](docs/配置.md)。

然后：

1. **放一份起始表**：把插件自带的 `resources/空模板.xlsx` 复制成 `data/queue.xlsx`。
   编辑器第一次启动时按它生成 `data/queue.json`；此后 json 是事实源，xlsx 变成导出镜像。
   **起始表与 json 都没有时编辑器不会挂载**（fail-closed：记一行 error 日志，机器人照常跑）。
2. **重启 Yunzai**——凭证是插件加载时交给编辑器的，改完不重启会出现「插件用新口令、编辑器还认旧口令」，
   填表链接直接 403。`notify.cron` 也是改了必须重启的键。
3. 在群里发 `#排队初始化`（**仅主人**）：口令与签名密钥、编辑器白名单、探活一次做完。
   **遇错即停**，已有产物只校验不覆盖。

编辑器挂在**机器人自己的端口**上（`server.port`，默认 2536），不是独立调试的 7788；
nginx 与安全口径见 [`editor/DEPLOY.md`](editor/DEPLOY.md)。数据目录固定 `<插件根>/data`，不可配置，
也不允许离开插件目录（`data/` 已被 git 忽略，所以更新只动代码不动数据）。

> **填表内容对全群可见**：编辑器口令在每个人的填表链接里，**拿到链接的人都能读到整张表**
> （群昵称、游戏名、选择与备注都在内）。本群成员还能改别人的行（受额度与三条红线限制），
> 所以别把隐私写进备注。

## 编辑器：入口、页面与权限

编辑器地址是 `<editor.public_url>/#code=<6 位数字>`（群聊里点进来就是这条路径），
深链 `#fill` 打开填写页。侧栏七个页面：**排队表 / 概览 / 清榜安排 / 历史版本 / 改动记录 / 权限管理 / 归属状态**；
填写页只有「排队中」「已完成」两块。页面与交互见 [`docs/编辑器-页面.md`](docs/编辑器-页面.md)。

**手机端（≤1100px）**侧栏收起，底部有通栏的页面下拉（选项按权限生成）；群成员点链接默认落到填写页
（地址栏已带 `#页面` 时不抢），「管理台 /」前缀只给管理身份，「当前选中」卡在手机上隐藏。
排队表在手机上每行一行读完（序号 / 群昵称 / 完成情况 / 呼叫），「编辑」是昵称右侧的小键，点开抽屉改整行。
填写页的「我的报名」按服务端下发的本人行（QQ 绑定 / 唯一同名）显示；同名多行认不出时写「待核对」。

**权限只按稳定 QQ 判**，群昵称不能当身份（白名单、主人名单是两份 QQ 清单）：

| 角色 | 能做什么 |
| --- | --- |
| 主人（`owner`，或页面带 `?a=<管理口令>`） | 全部：白名单与归属重建 / 清空无主行、周期清榜、呼叫成员、主播列表、历史版本与回退、改动记录 |
| 白名单管理员（QQ 在 `abyss-editor-admins.json`） | 改所有人的行、主播列表、历史版本与回退、呼叫成员、改动记录看全部；**不能**清榜，也没有权限管理与归属状态两页 |
| 群成员（有身份签名且在名单里） | 改整张排队区（自己的行不限；别人的行受额度与三条红线）、呼叫主播、收录临时成员名、改动记录（只看自己相关） |
| 不在名单里 / 链接过期 / 只有口令 | 只读 |

**群成员不是「只能改自己那一行」**：名单可信时整张排队区都能改，改别人的行有额度
（一次 ≤3 行、10 分钟 ≤10 行）和三条红线（清空别人的行、改别人行的群昵称、主播锁）；
名单不可信（空 / 超过 48 小时）时退回老口径：只能碰自己那一行、或新增且昵称是自己的行。
完整判据见 [`docs/编辑器-权限与归属.md`](docs/编辑器-权限与归属.md)。

**写表**：输入即改，停手 **1.2 秒**自动保存；每次保存带 `version`（页面读到的表指纹）与每行的
`fp`（行指纹），对不上回 **409**、一个字都不写——判的是**行级冲突**，不会把别人刚改的盖掉。
写失败不自动重试；版本冲突时草稿不动、自动保存暂停。详见
[`docs/编辑器-写入与安全.md`](docs/编辑器-写入与安全.md)。

## 使用与限制

**已知限制**

- 宿主命令冷却会吞消息：TRSS 的 `singleCD`（同群同一人，默认 2000ms）与 `groupCD`（同群，默认 500ms）
  在规则匹配**之前**丢弃消息，冷却期发 `#排队` 不会有任何回复。
- 表里**没有 QQ 号列**：认人靠群昵称 + QQ 绑定（首次按昵称认下，之后跟人走）。
- 表格被 Excel / WPS 打开时写入可能 `EPERM / EBUSY`：编辑器会提示关闭后重试，不会写坏原文件。
- 机器人出图的**主播排序仍按旧推荐度口径**（编辑器页面已按五档排序）——已知问题，
  改 `components/render.js` 的 `recRank` 即可。
- 清榜 / 翻状态 / 插队 / 退队都要求**编辑器已挂载**；起始表与 json 都缺时不挂载，这些动作直接报错。

**命令冲突**：规则分发先命中先执行（`priority` 升序）。会被别的插件抢在前面的命令：

| 被抢的命令 | 占用者 |
| --- | --- |
| `#幽境危战` / `#幻想真境剧诗` / `#深境螺旋` / `#深渊` / `#危战` / `#剧诗` | `Axiu-Plugin`「终局挑战」（priority 1） |
| `#排队` | 框架示例 `plugins/example/排队.js`（priority 500） |

所以本插件一律要求 `#排队 <榜>` / `#<榜>排队` / `#<榜>列表` 这类带后缀的写法。

**表格要求**（手工维护或替换起始表时）：必须是 `.xlsx`；每张表有一行表头且 **A 列写「序号」**，
表头之上是主播区；数据列按表头关键字识别；三列下拉会被当合法选项读出；A 列序号公式不要改。
完整清单见 [`docs/queue.schema.md`](docs/queue.schema.md) §9。

## 更新约定

| 命令 | 作用 |
| --- | --- |
| `#更新排队` | 框架 `#更新 abyss-queue` 的简写：拉最新代码并重启 |
| `#更新 abyss-queue` | 同上（完整写法） |
| `#强制更新 abyss-queue` | `reset --hard` 对齐远端，**丢弃被跟踪文件的本地改动** |
| `#全部更新` | 框架自带的全部插件更新 |

⚠️ `#更新 abyss`（缩写）**不生效**：框架命中但解析不出 `plugins/abyss`，命令被吃掉且无回复。

两条硬约定：

1. **配置与数据只以模板入库**：仓库跟踪 `config/config.yaml.example`，`config.yaml` 由首启复制，
   `data/` 被忽略 ⇒ 更新不会碰配置与数据。
2. **部署目录只由更新指令改动**：不要手工复制 / 编辑同步代码（会与远端提交重叠导致快进被拒）；
   改动先在源仓库落地并推送，再 `#更新排队`。
