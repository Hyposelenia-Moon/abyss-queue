# 编辑器部署（要点速览）

> 这里只放**要点**，够你看出该准备什么、该注意什么。
> 具体的 nginx / systemd 配置、逐步命令与排障表**不写进插件**，需要时找维护者要一份。
> 模块与接口见 [`README.md`](README.md)；权限与归属见 [`../docs/编辑器-权限与归属.md`](../docs/编辑器-权限与归属.md)。

## 一句话架构

**编辑器是唯一的写入口，而且与机器人同一个进程**：编辑器挂在 bot 自己的 HTTP server 上（前缀 `/queue`），插件直接读
`<插件目录>/data/queue.json`（**唯一事实源**，每次现读，没有快照、没有中转）。同目录的 `queue.xlsx` 是它的**导出镜像**
（给 Excel / 下载 / 历史版本用），由编辑器每次提交后重写。所有写操作经 `editor/service.js` 的进程内注册表直调编辑器，
插件不向它发 HTTP 请求。

## 要准备什么

| 项 | 说明 |
| --- | --- |
| Node | ≥ 20.11（用到 `import.meta.dirname`） |
| 依赖 | `jszip`、`yaml`：插件目录 `npm i --omit=dev` |
| 反向代理 | nginx（建议配 HTTPS），把 `https://example.com/queue` 转到 **bot 的端口**（`<Yunzai>/config/config.yaml` 里 `server.port`，默认 2536）。**不是 7788**——编辑器挂在 bot 自己的 HTTP server 上，7788 只是独立调试 / 套件的默认端口 |
| 数据目录 | **固定、不可配置**：`<插件目录>/data`（插件装在 `<Yunzai>/plugins/abyss-queue`，所以就是 `<Yunzai>/plugins/abyss-queue/data`）：`queue.json`（事实源）+ `queue.xlsx`（导出镜像）+ `queue.lock`（跨进程写锁，用完即删）+ `versions/` + `archives/` + 白名单 / 绑定 / 锁 / 群名单 / 口令登记簿。**不允许离开插件目录** |
| 进程守护 | 不需要单独守护：编辑器随 bot 起停（bot 挂了它就没了，bot 起来它就回来）。三个密钥在 `config/config.yaml` 的 `editor` 段里，不走命令行、也不走环境变量 |
| 起始表 | 把插件自带的 `resources/空模板.xlsx` 复制成 `<插件目录>/data/queue.xlsx`。编辑器第一次启动时按它生成 `data/queue.json`；此后 json 是事实源、xlsx 变成导出镜像。**起始表与 json 都没有时编辑器不会挂载**（fail-closed：记一行 **error** 日志、bot 照常跑） |

> 数据目录**固定、不可配置**：编辑器的状态文档与它派生的一切（`queue.xlsx` 镜像、`.bak`、绑定 / 白名单 / 锁 / 群名单 /
> `versions/` / `archives/`）都必须待在 `<插件根>/data` 里，`--file`（或 `ABYSS_EDITOR_FILE`）指到插件外就**拒绝启动**；
> 插件侧那些落点（`abyss-editor-bindings.json` / `abyss-editor-locks.json` / `abyss-editor-roster.json` 等）**本身就是
> `data/` 下的常量**，配置里连路径键都没有，所以没有"配到外面"这回事。`data/` 已被 git 忽略，所以框架的 `#更新`
> 只动代码不动数据。回归套件要指临时目录时用 `ABYSS_EDITOR_TEST_PATHS=1` 与 `ABYSS_QUEUE_*` 那组环境变量（**生产绝不要设**）。

## 三个密钥（**不要用同一个**）

都在机器人侧 `config/config.yaml` 的 `editor` 段（编辑器由宿主注入，只有这一份来源）。**留空即可**：`token` 与 `sign_key`
在**首次启动时由启动补齐自动生成**（只写这一次，之后不再动）；`admin_token` 按需手填。

| 配置键 | 作用 | 进不进链接 |
| --- | --- | --- |
| `editor.token` | 访问口令：能不能用这个服务 | **进**（每个人的链接里都有） |
| `editor.sign_key` | 身份签名密钥：你是谁、能改哪些行 | 不进（只留在机器人与编辑器） |
| `editor.admin_token` | 管理口令：主人维护白名单的备用入口（`?a=<这段>`） | 不进（可选，留空 = 不开这个入口） |

> 口令与签名密钥相同 = 任何拿到链接的人都能伪造别人的身份（包括主人）。正式部署务必让两者不同（启动补齐生成的本来就不同）；
> 手改成同一个时编辑器退回用口令签，并在启动日志里明确警告。

## 必须写对的几处

1. `editor.public_url` 填**对外那个地址**（`https://example.com/queue`，换成你的域名）；它只用来拼群里的填报链接，插件
   **不会请求它**。`editor.token` / `editor.sign_key` / `editor.admin_token` 是插件与编辑器**共用**的那一份，不用再去别处
   对齐；`roster.group` 填群号（**要在群里填**）。
2. `data/abyss-editor-admins.json` 的 `owner` 由**启动补齐首次自动写入**（主人 QQ 来自机器人配置）；要手工加白名单管理员时
   往 `admins` 里加 QQ 号，或在页面「权限管理」里加。
3. nginx 的 `client_max_body_size` 要够大（上传整张表，建议 32m）。
4. 表文件别用 Excel / WPS 直接打开着改（会写失败）。
5. **`--roster-qq`（`ABYSS_EDITOR_ROSTER_QQ`）保持默认 `"0"`，不要配成某个真人的 QQ**：编辑器的**路由闸**对"机器人身份"有一条
   豁免（带身份、没时间窗也放行）。插件现在走进程内直调、不再发 HTTP 请求，这条豁免只影响编辑器自己的路由（独立调试 /
   旧客户端）。配成真人 QQ 的话，那个人**不带时间窗**的身份链接也会跳过那条闸（身份仍是那个人自己，能改哪些行由归属与额度
   决定，不会因此变成别人）。宿主模式（挂在 bot 里）由插件注入 `ROSTER_QQ`，不受这一条影响。

## 部署后逐条验收

- `curl https://example.com/queue/healthz?k=<口令>`：`auth` / `sign_key` / `owners` / `roster` 都对
- 群友点自己链接：只看到、只改得动自己那一行；没签名的链接只读
- 机器人日志：`编辑器已挂到 bot 端口：/queue（表 …）`、`群成员名单已同步到编辑器：N 人`
- 主人页面：「历史版本」能列出、能回退、能下载；「归属状态」能打开；填写页左下角有身份卡
- 白名单管理员页面：同样能列出 / 下载 / 回退历史版本；但看不到「归属状态」（那一样是主人专属）

## 数据安全（已经做在代码里）

每次写表**前**存历史版本（滚动 20 份，可回退，回退也留一份）＋ 每月的最后一次修改长期归档（默认 12 个月）＋ 每日归档
只留最近 7 天；覆盖类操作先校验再原子替换，替换前落 `.bak`；退群删行会压紧（不留空洞）；空名单拒绝对账。

**链接身份与时间窗**：身份**只来自链接**（`u/s` 签名 QQ + 群昵称 + 签发时刻，30 天），权限**只问群成员名单**
（`isMember(qq)`：在名单里可写、不在只读、名单不可信走"只能改自己那一行"）。**没有设备认领**：不种设备 cookie、没有认领
记录文件。管理员及以上 24 小时内不必再带链接（`abyss_admin_ok` cookie），普通群友一律要带链接；链接带 5 分钟时间窗，
旧窗一律 410。**建议走 HTTPS**：外网 https 下 `abyss_admin_ok` 才会带 `Secure`（判据是 `req.socket.encrypted` 与反代的
`x-forwarded-proto`，nginx 记得把真实协议传下来）。

## 链接 = 身份凭证（威胁模型）

发给群友的填报链接**等同私钥**：

- 群里那条是**固定入口页 + 6 位数字短码**（`#code=123456`），短码 **5 分钟作废**；同一条短码在 5 分钟内可以被群里多人
  反复兑换（链接面向所有群成员，不一次性作废），换到的是同一条带身份的链接；
- 链接里签着 QQ 身份（30 天），外加 **5 分钟时间窗**（`w/ws`，只认当期与上一期）；窗口过期后普通群友必须回群里重新点一次
  `#排队`，管理员可凭 24 小时 cookie 继续；
- 拿到某人链接（转发、截图、翻群聊天记录）并在有效期内打开的人 = 该 QQ 本人，**可以写**多少由群成员名单、额度、两条红线与
  主播锁决定；
- 留痕（`data/abyss-editor-changes.json`）记的是**链接主人的 QQ**。

所以：**不要把链接外传**；怀疑泄露就等窗口过期（≤5 分钟）或让对方重新发一次 `#排队`。目前**没有** owner 一键作废入口
（先记在需求上）。
